# Kino Telegram Plugin

Plugin para **Kino TV** que permite explorar, buscar y reproducir videos y contenido multimedia directamente desde canales públicos de Telegram.

## Instalación en Kino TV

1. Abre la aplicación **Kino TV**.
2. Ve a **Ajustes > Plugins**.
3. Escribe el identificador de tu repositorio: `tu-usuario-de-github/kino-plugin-telegram`
